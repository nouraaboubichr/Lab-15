# Exercice 1 - Expressions lambda et interfaces fonctionnelles

* Découvrir les **expressions lambda** introduites en Java 8 pour représenter des fonctions anonymes.
* Créer une **interface fonctionnelle** avec `@FunctionalInterface` et l’utiliser avec une expression lambda.
* Utiliser les interfaces standard de **`java.util.function`** : `Predicate`, `Consumer`, `Function` et `Supplier`.
* Utiliser les versions spécialisées pour les types primitifs : `IntPredicate`, `IntConsumer`, `IntFunction` et `IntSupplier`.
* Explorer les différentes syntaxes des lambdas : sans paramètre, avec un ou plusieurs paramètres et avec un bloc de code.
* Comprendre la **capture des variables** locales et de `this` dans les lambdas.
* Utiliser les **références de méthodes** pour simplifier certaines expressions lambda.
* Exploiter l’API **Stream** pour filtrer, transformer, compter et grouper les données.
* Utiliser des opérations avancées comme `groupingBy`, `average`, `max`, `filter` et `map`.
* Composer des fonctions avec **`andThen`**, **`compose`**, ainsi que des `Predicate` avec `and`, `or` et `negate`.
* Gérer les **exceptions dans les lambdas** avec une interface fonctionnelle personnalisée comme `IOFunction`.
* Créer un système de **validation flexible** avec `Predicate` et des règles de validation.
* Implémenter une **`TriFunction`** à trois paramètres et utiliser `andThen`.
* Utiliser les Streams pour analyser des fichiers Java, notamment pour **compter les `TODO`**.
* Créer des **comparateurs composés** avec `Comparator.comparing()` et `thenComparing()`.
* Calculer une **factorielle avec `IntStream`** dans une approche fonctionnelle.
* Implémenter un **memoizer générique** avec `Function` et `ConcurrentHashMap` afin de mettre en cache les résultats.
* Ce TP permet de rendre le code Java plus **expressif, modulaire et adapté aux architectures modernes**.
